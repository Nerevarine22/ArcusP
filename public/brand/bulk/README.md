# BULK brand assets

Source: https://www.bulk.trade/brand (reviewed 29 October 2026).

- `logo.svg`: original https://www.bulk.trade/assets/bulkx-logo-dark.svg
- `symbol.svg`: first path of that SVG, cropped to the original star; shape unchanged.
- `plex-sans.woff2`: IBM Plex Sans Latin from the official site's stylesheet, original asset `03fc1b4a8d284b5e-s.p.af4fcd24.woff2`.
- `plex-mono.woff2`: IBM Plex Mono Latin, original asset `effe91970fc4db64-s.p.19510058.woff2`.

The calculator uses the exchange's warm dark `#1B1A14` palette, light text and muted gold selections, following the supplied trading-terminal reference. Original dark logo files remain unchanged; CSS displays them in white on the calculator. This is an independent community tool.
