# Variational brand assets

The SVG wordmark and symbol were taken from the public header at https://omni.variational.io/perpetual/BTC on 28 October 2026.
The original paths are preserved. `currentColor` is resolved to light text or the official blue (#4C9AF8) for use in an external image.

Calculator assumptions: the linked official token documentation specifies a 32% Genesis distribution, but does not specify total token supply. The editable 1B supply matches the user's reference grid. The editable 10M points pool is a model assumption, not an official final total.
